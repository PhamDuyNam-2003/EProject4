# API Gateway

## Gateway Responsibility
Là điểm vào duy nhất cho toàn bộ request từ Client.

## Authentication
Kiểm tra JWT Token.

## Routing
Định tuyến request.

## Rate Limiting
Giới hạn số lượng request.

## Logging
Ghi log tập trung.

## Load Balancing
Phân tải lưu lượng.

## Service Discovery
Khám phá địa chỉ IP các services.
